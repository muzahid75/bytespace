# ByteSpace (Next.js 15 + Tailwind v4 + shadcn/ui)

    npm install
    npm run dev

Tokens (colors, radii, Poppins/Satoshi fonts) come from the Figma style guide and live in `app/globals.css`.
Add more shadcn components any time: `npx shadcn@latest add dialog select ...`

Routes: `/` Home · `/login` · `/register` · `/search` · `/courses/[slug]` (About / Lessons / Reviews tabs) · 404
